# pEQ Neural Workstation 🧠🎶

**pEQ** is an industrial-grade, AI-powered media workstation designed for high-fidelity audio production, analysis, and playback. Built with a focus on neural signal processing and distraction-free visualization, it bridges the gap between consumer media players and professional studio environments.

---

## 🚀 Key Features

### 🧠 Neural DSP & Analysis
*   **7-Band Parametric EQ**: Precise tonal shaping with high-fidelity filtering.
*   **AI Stem Splitting**: Real-time vocal and instrumental separation for deep-track analysis.
*   **Live RTA Visualizer**: Studio-grade Real-Time Analyzer for spectral frequency monitoring.
*   **Phase Inversion & Sub-Harmonic Generator**: Advanced acoustic control for professional monitoring.

### 🎥 Immersive Multitasking
*   **Universal Picture-in-Picture (PiP)**: High-fidelity background visualization for both video and audio telemetry.
*   **Neural Focus Mode**: A dedicated lock-screen overlay featuring distraction-free synced lyrics and minimal transport controls.
*   **Lifecycle-Aware Brightness**: Automated display backlight management for maximum power efficiency in background states.

### ☁️ Cloud & Stream Integration
*   **Real-time Stream Resolution**: Industrial-grade support for YouTube and network media sources via `youtube-dl` integration.
*   **Neural Cloud Bridge**: Seamlessly resolve and stream high-fidelity audio from diverse cloud providers.

### 🎨 Workstation Aesthetics
*   **Dynamic Neural Coloring**: Interface and widgets dynamically synchronize their color palettes (Dominant/Vibrant) with track artwork.
*   **Workstation-Grade Widgets**: Professional-grade Glance and XML widgets for immediate tactical control from the home screen.

---

## 🛠 Technology Stack
*   **Core**: Kotlin Multiplatform (KMP)
*   **UI**: Compose Multiplatform / Material 3
*   **Audio Engine**: ExoPlayer / Media3 with custom DSP wrappers
*   **AI Engine**: ONNX Runtime for Neural Stem Separation
*   **Networking**: Ktor / youtube-dl-android

## 📦 Installation & Setup

1.  **Clone the Repository**:
    ```bash
    git clone https://github.com/I-am-Manu-Singh/pEQ-Media-App.git
    ```
2.  **Open in Android Studio**:
    Ensure you have the latest **Android Studio (Ladybug or later)** and the **Kotlin Multiplatform** plugin installed.
3.  **Sync Gradle**:
    Let the workstation initialize its industrial dependencies.
4.  **Run**:
    Deploy to your hardware or emulator using the `composeApp` run configuration.
